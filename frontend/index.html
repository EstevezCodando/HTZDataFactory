O que é

O HTZDataFactory converte dados geoespaciais abertos para o formato binário ATDI, nativo do HTZ e ICS Telecom. Você define uma área no mapa; o sistema busca as fontes, processa e entrega um ZIP pronto.

O que é gerado

Arquivo Conteúdo Resolução Fonte
.geo Modelo digital de terreno (elevação) 30 m/pixel FABDEM v1.2
.sol Clutter — tipo de superfície 30 m/pixel MapBiomas Coll. 10
.pal Paleta de cores do clutter — Gerado
.img Imagem de satélite grayscale 15 m/pixel Sentinel-2 L2A
manifesto.json Metadados, fontes e disclaimer — Gerado

Dois modos de uso

  • Gerar por Área — desenhe um retângulo no mapa. O sistema busca dados automaticamente e gera o pacote.
  • Converter Arquivo — envie seu próprio GeoTIFF e converta para ATDI binário.

Como usar

  • 1. Selecione o basemap — use o seletor no canto superior direito do mapa.
  • 2. Desenhe o retângulo — clique na ferramenta de retângulo na barra do mapa e arraste sobre a área de interesse.
  • 3. Escolha as camadas — selecione quais arquivos quer gerar: .geo, .sol, .img.
  • 4. Gerar — clique em Gerar pacote HTZ. O log exibe o progresso em tempo real.
  • 5. Download — quando concluído, o link de download aparece no log.

Grade FABDEM no mapa

A grade exibe os tiles FABDEM 1°×1° disponíveis localmente. Tiles não baixados são obtidos automaticamente do servidor da Universidade de Bristol na primeira requisição — o processo demora mais na primeira vez, e nas seguintes o tile já está em cache.

Limites recomendados

Área Dimensão Tempo estimado
0,5° × 0,5° ~55 × 55 km 30–60 s
1° × 1° ~111 × 111 km 60–120 s
2° × 2° ~222 × 222 km 2–5 min
Áreas acima de 3°×3° não são recomendadas — consomem muita RAM e podem levar vários minutos.

Como converter

  • 1. Tipo — selecione o tipo de saída: DEM (.geo), Clutter (.sol) ou Imagem (.img).
  • 2. Formato do clutter — ao selecionar Clutter, escolha se o seu TIFF está em formato MapBiomas (códigos 0–48, reclassificados via CSV) ou já no padrão ATDI (códigos 0–9, usados diretamente).
  • 3. Arquivo — arraste ou clique para selecionar o GeoTIFF.
  • 4. Converter — o sistema reprojeta para UTM e gera o binário ATDI.
  • 5. Download — link aparece no log quando a conversão termina.

Usando seu próprio MapBiomas

  • Exporte a área de interesse em mapbiomas.org como GeoTIFF de classificação (1 banda, UInt8).
  • Use Converter Arquivo → Clutter → Formato MapBiomas. A tabela de reclassificação padrão é aplicada.

Criando um TIFF já no padrão ATDI

Se você já sabe os tipos de clutter da sua área, pode produzir um TIFF diretamente com os códigos 0–9. Selecione Formato ATDI direto no upload — os valores são usados sem reclassificação. Consulte a aba Formatos para a tabela completa de códigos, cores e atenuações.

Usando seu próprio DEM

Compatível com SRTM, ALOS AW3D30, Copernicus DEM, FABDEM ou qualquer GeoTIFF de elevação em metros. Qualquer projeção é aceita — reprojetado para 30m UTM.

Usando imagem de satélite ou ortofoto

Envie GeoTIFF RGB (3 bandas) ou grayscale (1 banda). O sistema normaliza para 8-bit e reprojeta para 15m UTM.

Requisito geral: GeoTIFF com CRS definido, ou acompanhado de arquivo .tfw no mesmo diretório (o sistema assume WGS84 nesse caso).

Tabela de clutter HTZ — códigos ATDI

Cada pixel do .sol contém um código inteiro (0–9) que o HTZ usa para definir a altura efetiva do obstáculo naquele pixel — afetando perda por difração nos modelos de propagação (ITU-R P.526, Longley-Rice, etc.).

Código Nome ATDI Cor no HTZ Altura clutter Atenuação típica Uso / fonte
0 open Branco 0 m 0 dB Campo aberto, água, nodata. Sem atenuação adicional.
1 suburban Azul claro 8 m ~5–8 dB Suburbano, residencial baixo, bairros periféricos.
2 urban_8m Azul 8 m ~10–12 dB Urbano base — periferia de centros urbanos. Ponto de partida do efeito cebola.
3 urban_15m Laranja 15 m ~15 dB Urbano médio — gerado automaticamente pelo efeito cebola (anel de 300m).
4 urban_30m Verde-água 30 m ~20 dB Urbano denso — gerado pelo efeito cebola (anel de 600m).
5 forest Verde 15 m ~10–15 dB Floresta densa, dossel fechado (Amazônia, Mata Atlântica).
6 hydro Verde claro 0 m 0 dB Superfície aquática — rios, lagos, reservatórios. Sem obstáculo.
7 urban_50m Amarelo 50 m ~25 dB Centro urbano consolidado — gerado pelo efeito cebola (anel de 900m).
8 wood Marrom 8 m ~6–10 dB Cerrado, caatinga, vegetação arbustiva — dossel aberto.
9 roof Vermelho 5 m ~3–5 dB Telhado, superfície impermeável — áreas edificadas não classificadas como urbano.
Altura de clutter vs. atenuação: o HTZ usa a altura de clutter (coluna "Altura clutter") nos modelos de propagação para calcular perda por difração adicional sobre o terreno — não é uma perda fixa em dB. Os valores de atenuação típica acima são referências para modelos empíricos como Okumura-Hata e COST-231. Os valores exatos dependem da frequência, geometria do enlace e modelo selecionado no HTZ.

Como criar um TIFF pronto para .sol

Você pode produzir seu próprio TIFF de clutter em dois formatos:

Opção A — Formato MapBiomas (reclassificação automática)

Use quando você exportou dados do mapbiomas.org ou tem um mapa de uso do solo com a classificação MapBiomas:

  • 1 banda, tipo UInt8 ou UInt16
  • Valores inteiros representando classes MapBiomas (ex: 3 = Floresta Ombrófila, 24 = Área Urbanizada)
  • O sistema aplica a tabela config/mapbiomas_atdi.csv automaticamente
  • No upload, selecione "Formato MapBiomas"

Opção B — Formato ATDI direto (sem reclassificação)

Use quando você já sabe o tipo de clutter de cada região e quer controle total sobre o resultado:

  • 1 banda, tipo UInt8
  • Valores 0 a 9 conforme a tabela acima (0 = open, 1 = suburban, 5 = forest, etc.)
  • Cada pixel já contém o código ATDI final — nenhuma reclassificação é aplicada
  • No upload, selecione "Formato ATDI direto"

Exemplo de criação em Python com rasterio:

import numpy as np, rasterio
from rasterio.transform import from_bounds
from rasterio.crs import CRS

# Grade 100x100 px — WGS84, bbox exemplo
arr = np.zeros((100,100), dtype=np.uint8)
arr[20:40, 20:40] = 5   # floresta
arr[60:80, 60:80] = 2   # urbano_8m (cebola vai expandir automaticamente)
arr[10:20, 70:80] = 6   # hidrografia

transform = from_bounds(-47.5, -16.0, -47.0, -15.5, 100, 100)
with rasterio.open(
    "meu_clutter.tif", "w",
    driver="GTiff", height=100, width=100,
    count=1, dtype=np.uint8,
    crs=CRS.from_epsg(4326),
    transform=transform,
) as dst:
    dst.write(arr, 1)
# Envie meu_clutter.tif → Converter Arquivo → Clutter → Formato ATDI direto

Efeito cebola urbano

O que é: o efeito cebola é uma técnica de pós-processamento aplicada automaticamente pelo sistema sobre pixels classificados como urban_8m (código 2). Ele expande a área urbana em anéis concêntricos com alturas de clutter crescentes, simulando o gradiente real de densidade das cidades — onde o centro tem edificações mais altas que a periferia.

Como funciona: a partir de cada pixel urban_8m, o sistema aplica erosão morfológica em três passadas de 300m cada (≈ 10 pixels a 30m/pixel):
   • Anel externo (300m): mantém urban_8m — 8m de altura
   • Anel intermediário (300–600m): eleva para urban_15m — 15m
   • Anel interno (600–900m): eleva para urban_30m — 30m
   • Núcleo (acima de 900m): eleva para urban_50m — 50m

Quando desativar: se o seu TIFF já contém os códigos urbanos corretos (2, 3, 4, 7) mapeados manualmente, desmarque a opção "Aplicar efeito cebola urbano" no upload para evitar dupla expansão.

Limitação: o efeito cebola é uma aproximação estatística — não representa a geometria real dos edifícios. Para simulações de alta precisão, use dados de footprint de edificações.

O .sol ficou sem dados na minha área

O MapBiomas local cobre apenas a área do arquivo TIF montado no servidor. Verifique o retângulo azul no mapa — sua seleção deve estar dentro dele. Para outras regiões, use Converter Arquivo → Clutter.

Tiles vermelhos no mapa impedem a geração?

Não. Tiles vermelhos são baixados automaticamente quando necessários, diretamente do servidor da Universidade de Bristol. A primeira requisição demora mais; as seguintes são imediatas.

Como abrir no HTZ

Descompacte o ZIP. No HTZ : File → Import → ATDI Files. Selecione o .sol ou .geo — o software carrega automaticamente os demais arquivos do mesmo diretório com o mesmo nome base.

Tamanho máximo de área

Recomendamos até 2°×2° (~222km×222km). Para projetos maiores, divida em blocos.

Posso usar minha própria tabela de reclassificação?

Sim. Edite config/mapbiomas_atdi.csv no servidor — nenhum rebuild Docker é necessário. Colunas: codigo_mapbiomas, nome_mapbiomas, codigo_atdi, nome_atdi, justificativa.

Sentinel-2 não encontrou imagem

O sistema busca cenas com menos de 20% de nuvens nos últimos 3 anos. Em regiões com cobertura persistente de nuvens, use Converter Arquivo → Imagem.

Como escalar workers

No servidor: docker compose up --scale worker=4 -d. Cada worker usa ~2 GB de RAM no pico.
